# Java DSA

A collection of Data Structures and Algorithms implemented in Java.

This repository contains implementations of fundamental algorithms,
Dynamic Programming problems, Data Structures, Sorting, Searching,
Graph Algorithms, Cryptography, and Competitive Programming problems.

## Topics Covered

- Sorting Algorithms
- Searching Algorithms
- Data Structures
- Dynamic Programming
- Graph Algorithms
- Hashing
- String Algorithms
- Cryptography
- Competitive Programming

## Algorithms Implemented

### Sorting

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

### Dynamic Programming

- 0/1 Knapsack
- Fibonacci
- Longest Common Subsequence
- Coin Change

### Data Structures

- Stack
- Queue
- Linked List
- Binary Search Tree
- AVL Tree
- Min Heap
- Max Heap

### Cryptography

- SHA-256 from Scratch

## Language

Java

This repository is maintained for learning, algorithmic problem solving,
